# v4 notebooks - start here

One notebook per step per engine. Run the steps in order: each model starts from what the previous one learned.

| Step | Question | Rotax 912 ULS | Rotax 914 ULF | Rotax 915 iS | Rotax 916 iS |
|---|---|---|---|---|---|
| 0 | Prepare the data | `phase0_scalers_912.ipynb` | `phase0_scalers_914.ipynb` | `phase0_scalers_915.ipynb` | `phase0_scalers_916.ipynb` |
| 1 | Is anything wrong? | `phase1_detection_912.ipynb` | `phase1_detection_914.ipynb` | `phase1_detection_915.ipynb` | `phase1_detection_916.ipynb` |
| 2 | Which part is failing? | `phase2_diagnosis_912.ipynb` | `phase2_diagnosis_914.ipynb` | `phase2_diagnosis_915.ipynb` | `phase2_diagnosis_916.ipynb` |
| 3 | How bad is it? | `phase3_severity_912.ipynb` | `phase3_severity_914.ipynb` | `phase3_severity_915.ipynb` | `phase3_severity_916.ipynb` |
| 4 | Is it the engine, or a sensor? | `phase4_sensor_fault_912.ipynb` | `phase4_sensor_fault_914.ipynb` | `phase4_sensor_fault_915.ipynb` | `phase4_sensor_fault_916.ipynb` |
| 5 | How worn is the engine? | `phase5_health_912.ipynb` | `phase5_health_914.ipynb` | `phase5_health_915.ipynb` | `phase5_health_916.ipynb` |
| 6 | How many hours are left? | `phase6_rul_912.ipynb` | `phase6_rul_914.ipynb` | `phase6_rul_915.ipynb` | `phase6_rul_916.ipynb` |

Every notebook has the same six parts: the data, training, a scorecard, a picture of it working on unseen flights, and what it means in plain words.

To train everything without opening a notebook, use `run.py` - the notebooks then just load its results. These files are generated by `make_notebooks.py`; edit that, not the notebooks.
